# Interview Prep Toolkit

A production-grade collection of core data structures, algorithms, and technical interview staples implemented cleanly in Python.

## Features
* **O(1) LRU Cache:** Implements a Least Recently Used (LRU) Cache combining a Hash Map and a Doubly Linked List (`OrderedDict`) to achieve constant-time $O(1)$ lookups, updates, and evictions.

## Project Structure
* `lru_cache.py` - The core LRU cache implementation and verification test suite.
